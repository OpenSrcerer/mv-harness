# songs/

Drop test songs here. Everything in this folder except this file is gitignored.

Needed before the build pass (W0 spike):
- 1–2 songs with **clear lead vocals**, ideally ones that have synced lyrics on [lrclib.net](https://lrclib.net), so lyrics,
  word alignment, vocal range and lip-sync can be validated.
- Optional: a `.lrc` or `.txt` lyrics file next to a song with the same base name (`My Song.flac` + `My Song.lrc`).

The two instrumental-leaning reference songs live in `../viz/` (`MEGAFAUNA.flac`, `Versatile.flac`) and are used from there.
