# Contract fixtures (tests/contract/)

Generated test fixtures for the mv-harness output contract (docs/CONTRACT.md). Everything here except this README is
**generated and gitignored**; regenerate it with one command:

```powershell
Set-Location <repo>; . .\scripts\mvh-env.ps1 -Offline
uv run --frozen --no-sync python -m tests.synth.build                 # synth (+ real-* when tests/.cache/real/ exists)
uv run --frozen --no-sync python -m tests.synth.build --only synth    # tests/contract/synth/ only (~20 s)
uv run --frozen --no-sync python -m tests.synth.build --only real     # tests/contract/real-*/ only (~5 min first time)
uv run --frozen --no-sync python -m tests.synth.build --check         # rebuild synth in a temp dir, diff against .done.json
```

The gate (and `tests/unit/fixtures/conftest.py`) runs the synth build when `tests/contract/synth/.done.json` is
missing. The synth build is **byte-identical on rerun** (`.done.json` holds the sha256 of every file; `--check` and
`tests/unit/fixtures/test_fx_determinism.py` verify it).

## tests/contract/synth/ — the synthetic song (ground truth)

"Lanterns on the Tide", 56.5 s, 44.1 kHz stereo, 120 BPM, A minor, generated by `tests/synth/song/` from a score:

| t (s) | bars | section | content |
|---|---|---|---|
| 0.0-0.5 | - | - | digital silence (pre-roll) |
| 0.5 | 0 | pickup | one-beat pickup (snare on beat 4 of bar 0, D12) |
| 1.0-9.0 | 1-4 | S01 intro#1 | kick, straight hats, pad; tom fill in bar 4 |
| 9.0-17.0 | 5-8 | S02 verse#1 | swung groove (8th swing 1.5), syncopated kick/bass; call-and-response V1 / V2 |
| 17.0-25.0 | 9-12 | S03 chorus#1 | crash + impact, ride, piano arpeggio; duet (V1 lead, V2 harmony on backing_vocals) |
| 25.0-34.5 | 13-17 | S04 bridge#1 | EDM **build** R01 (bars 13-16: snare roll, riser), bar 16 in **3/4**, bar 17 **digital silence** |
| 34.5-50.5 | 18-25 | S05 chorus#2 | the **drop** R02: four-on-the-floor, duet repeat (bars 18-21), instrumental (22-25) |
| 50.5-56.5 | 26-28 | S06 outro#1 | light groove, final hit at 52.5 s, decay through bar 28 (no pulse) |

Two singers: V1 = SAPI "David" (character C1, The Lamplighter), V2 = SAPI "Zira" (C2, The Tide). Each word is rendered
by SAPI, then LPC-resynthesised at a programmed note (vibrato, glide), so **f0 truth is exact**. Lyrics are invented.

What is exact (from the generator) and what is not — every file's `provenance.params.truth` says which:

| truth kind | files / fields |
|---|---|
| `fixture` (exact) | beats, bars, meter change, pickup, pulse regions, sections, phrases, EDM roles, counts (+ accents formula), grooves, drum hits (t = one-shot's first sample, velocity), notes (bass, piano, other = pad, guitar = none, vocals), chords, key, lyrics lines/words (t, d), voices/singing, vocal f0/midi/voiced curves, impacts/stops/silences/decay tails (times), hit points, holds, cues, stems (the generator tracks) |
| `measured` | band/fine/timbre/stereo/flux curves, spectrum128 (an *approximation* of the viz map), loudness curves and meta/loudness.json, stem levels/activity, dynamics levels — reference measurements of the rendered audio (`tests/synth/song/analysis.py`), not the production algorithms |
| `synthetic` (no physical truth) | mood, instrument probabilities and segments, vocal style probabilities, visemes/phonemes (dictionary ARPAbet timed inside truth words), moments ranking, meaning (intent.md / authored.json / meaning.json are invented examples) |

Invariants: stems are on the 24-bit grid and sum **exactly** to the mix (`vocals = lead + backing`, `drums = Σ sub-stems`,
`mix = vocals + drums + bass + guitar + piano + other`, `instrumental = mix − vocals`); guitar is digital silence.

Extra (non-contract) content:
- `_intermediate/<stage>/` — cache-only outputs (canonical.wav, separate_fast stems + separation.json, allin1.json,
  activations.f32, embeddings.f32), as `mvh.contract.fixture.run_stub` expects.
- `_truth/truth.json` — the scoring sidecar (every event with its sample index, formulas, word nuclei, notes...);
  `_truth/synth-song.flac` — **the input file** (tags + attached cover art) for `mvh analyze`;
  `_truth/lyrics_input.lrc|.txt` — a user lyrics file for `--lyrics`; `_truth/voices/V1.flac, V2.flac` — each voice alone.
- `.done.json` — sha256 of every file + validation errors (must be empty).

`lib/` is not included (the runner's finalize step copies it); `schema/` is.

End to end: `mvh analyze tests\contract\synth\_truth\synth-song.flac --out out\_wip\<agent>\synth --no-network` runs every
stage (stubs copy from this folder; real ingest decodes the input and reproduces `pcm_sha256`).

## tests/contract/real-<slug>/ — real songs (adapters, NOT ground truth)

Thin adapters (`tests/synth/real.py`) convert the W0 raw outputs in `tests/.cache/real/` into the contract layout. Use them
as **real upstream inputs** (set `MVH_FIXTURE_DIR=tests/contract/real-<slug>`): only the stages listed as `full` copy
cleanly through the stubs. Lyric text exists only in their `lyrics/` files (gitignored); never print it.
Big audio is hard-linked (canonical.wav, fast/*.wav) or encoded once to 24-bit FLAC (stems).

Coverage (`coverage.json` in each folder has the per-output detail):

| stage | megafauna | versatile | jeremy | newton-vs-nye | from (W0 raw) |
|---|---|---|---|---|---|
| ingest | full | full | full | full | decode/mix.wav + decode.json |
| identity | full | full | full | full | ffprobe tags |
| separate_fast | full | full | full | full | demucs/htdemucs |
| separate_hq | full | full | full | full | sep/ (rocm, karaoke, DrumSep) |
| allin1 | full | full | full | full | allin1/ (embeddings = mean over the 4 stems, dim 192) |
| rhythm | full | full | full | full | beat_this (minimal postprocessor, no fusion; MEGAFAUNA tempo octave not arbitrated) |
| spectral | partial | partial | partial | partial | spectral_proto curves + spectrum128 (no hit/onset events, no slope/balance, no mid/high raw hits) |
| loudness | full | full | full | full | spectral_proto curves + ffmpeg ebur128 (true peak) |
| harmony | partial | partial | partial | partial | key (S-KEY + KS agree flag), chords (lv-chordia raw); no chroma12 |

Absent everywhere: stem_activity, drums, instruments, mood, dynamics, choreo, cues, meaning, brief, viewer, frames.
