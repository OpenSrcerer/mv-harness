# mv-harness

Song analysis harness for AI agents that make music videos. Give it one song and it writes a self-contained folder of
timestamped metadata: tempo, beats and counts, sections, spectral bands, loud and quiet parts, stems, instruments, notes,
vocal range, word-timed lyrics, mood, the meaning of the song (as the user tells it), and a viewer to check and correct all of it.
It does not render video. It is the shared ground truth for agents that do, in whatever technology they choose.
