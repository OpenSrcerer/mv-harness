# M5 Words: contract decisions and additions (builder-m5)

Scope: stages `identity`, `lyrics`, `voices`, `lipsync`. Everything below is **additive** (optional fields or
interpretations of frozen fields) unless marked **CR** (needs the W3 integrator). Frozen fields are filled as
CONTRACT.md defines them. No lyric text appears in any log, warning, summary, provenance or error.

## Dependencies and inputs

- **M5-D1 lyrics reads ingest's `embedded_lyrics.json` through the D8 path (CR-M5-1).** The brief allows adding
  `ingest` to the lyrics deps, but `tests/unit/contract/test_deps_match_plan` pins the PLAN §3.2 deps and the gate
  must stay green, so the dep is NOT added. `lyrics.core._ingest_upstream` uses `ctx.upstream("ingest")` when the
  dep is declared and otherwise ingest's cache dir from the job (`ingest_dir`, the same directory D8 opens for
  `ctx.audio('mix')`). The cache key is still correct: identity depends on ingest, lyrics on identity. CR-M5-1 asks
  W3 to add `ingest` to lyrics' deps and `"lyrics": {"identity", "ingest", ...}` to `PLAN_DEPS` in that test; the
  code then switches automatically.
- **M5-D2 Cascade order** = PLAN R11: `--lyrics` file > embedded tags > LRCLIB > faster-whisper transcription.
  LRCLIB is queried whenever there is no user file; an embedded *plain* text whose words agree with a *synced*
  LRCLIB entry (LCS F1 >= 0.85) takes LRCLIB's line timings (`source.kind = lrclib`, a provenance note says so).
- **M5-D3 LRCLIB ranking** (SPIKE): title gate token-set >= 90 and artist >= 85 (parenthesised tags ignored);
  among candidates within 2 s prefer synced, then word sync, then the smallest |Δdur|; 2-5 s accepted with
  `version_mismatch`; > 5 s rejected. Requests: get+album, get, search(track, artist), search(q), 0.4 s apart,
  identifying User-Agent `mv-harness/0.1 (https://github.com/OpenSrcerer/mv-harness)`; never `/api/get-cached`.
  The Lyricsfile (YAML) is used when `hasWordSync`.
- **M5-D4 identity looks up MusicBrainz by default in `max`** (`verify: true`; `draft` keeps the tags only).
  Order: ISRC lookup, recording search with `dur:[d-3 s TO d+3 s]` (full title, then without the parenthesised
  version tag), then plain searches paged (limit 100, 2 pages). Credits from the recording's artist relationships
  and its work (composer, lyricist). Tags stay authoritative for title/artist/album when present; `conf` 0.98 when
  tags and MusicBrainz agree, 0.9 tags only (lookup skipped/offline), 0.85 tags with no MB match. Offline without a
  cached response the stage keeps the tags (`fallbacks: identity:offline`), it never fails.

- **M5-D18 the vocal stem**: lyrics, voices and lipsync use `lead_vocals` (SPIKE) unless its p95 envelope is
  more than 20 dB below the `vocals` stem's; then they use `vocals` (fallback tags `lyrics:vocals_stem`,
  `voices:vocals_stem`, `lipsync:vocals_stem`; `alignment.stem`, `meta/voices.json.stem`, lipsync summary
  `stem`). MEGAFAUNA's karaoke split put the whole voice into backing (lead p95 -74 dBFS vs vocals -19 dBFS).
  Duet backing spans are only looked for when the lead stem is used.

- **M5-D19 VAD retry**: when the Silero-VAD pass keeps fewer than 0.15 ASR words per active vocal second (and there are >= 10 s of vocal activity)
  (`asr_vad_retry_wps`), faster-whisper runs again without VAD (temperature 0, same filter incl. the activity
  mask) and that result is used when it holds more than twice the words, at least 8, with mean p >= 0.5 (fallback
  `lyrics:asr_no_vad`, `asr.vad_retry` records both counts). MEGAFAUNA (processed EDM voice): VAD 2 words,
  no VAD 75 words, LCS F1 vs the embedded text 0.00 -> 0.53. Jeremy (0.57 w/s) and newton never trigger it.
- **M5-D20 G1 needs ASR evidence** (refines bench-words §5): fewer than 8 ASR words -> G1 does not apply
  (`checks.G1.note = asr_insufficient`); mean ASR word p < 0.70 -> a G1 failure is an ordinary fail
  (`asr_unreliable`, grade C at best when it is the only other problem) instead of the "wrong text" verdict D.
  A confident ASR that disagrees with the text still gives D.

## lyrics/lyrics.json additions

- `source.format` (lrc, txt, srt, vtt, lyricsfile, transcribed), `source.offset_s` (the detected global offset,
  CTC minus source, G6), `source.offset_applied_s` (applied when |offset| > 0.15 s), `source.version_mismatch`
  (|offset| > 3 s, or an LRCLIB duration 2-5 s off).
- `gate`: the G1-G8 checks `{value, threshold, pass}` (pass null = not applicable) and the grade; `asr` (engine,
  segment/word counts, filter drops, mean word probability, precision/recall); `alignment` (mode `synced` /
  `anchored` / `whole_song`, group notes, engine torchaudio|vendored, ASR-repaired words, added lines, activity
  source); `lrclib` (status, request statuses, top candidates with ids/Δdur/flags, the choice). No text.
- `words[].flags` values: `interpolated` (no CTC placement), `asr_repaired`, `expanded`, `asr_only`, `backing`.
- **M5-D5 `grade`** follows docs/spike/bench-words.md §5 exactly (never the per-line mean score). For a
  transcription there is no reference text: `lyrics_match_score = null`, grade B when G2-G4 pass and the mean
  whisper word probability >= 0.85, C otherwise, D below 0.6 or when coverage < 0.60.
- **M5-D6 `coverage`** = G2 (words with MMS score >= 0.10).
- **M5-D7 word `d`** is the sung duration, not the raw CTC span: each word's end is extended while the
  lead-vocal envelope stays within 20 dB of p95, never past the next word's start (last word of a line: at most
  1.5 s). Raw CTC spans end long before a sustained vowel does (SPIKE).
- **M5-D8 line `t`/`d`** = first word start .. last word end; ids `L001..` in start order (ties: source order);
  `section_id` = the section with the largest overlap; `text_group` = identical normalised text (`T01..`, first
  appearance); `repeat_group` = near-identical lines (rapidfuzz ratio >= 88) occurring >= 2 times (`LG01..`).
- **M5-D9 `timing_source`**: `ctc` (MMS), `user` (user word timings kept verbatim, or an override applied),
  `lrclib_word` / `lrclib_line` (source times + offset when CTC failed), `stable_ts`, `whisper` (an ASR-only line
  CTC could not place), `interpolated` (expanded repeats with no confident CTC placement).
- **M5-D10 user word timings are authoritative**: an A2/VTT/Lyricsfile with word times from `--lyrics` is kept
  verbatim; the alignment only feeds confidence and the gate.
- **M5-D11 lines are only ever ADDED**: repeat expansion adds a supplied line where the ASR heard it and no
  supplied line covers that time (fuzzy >= 60 over 1-3 consecutive unique lines; for synced sources also no source
  line within ±2 s); ASR-only lines (`asr_only` flag, `timing_source` ctc/whisper) are added only outside the lyric
  span or in gaps >= 4 s, with mean word probability >= 0.7, >= 3 words and no fuzzy match (< 45) to any supplied
  line; before the first or after the last lyric line, p >= 0.6 and "not a repeat" (fuzzy < 60) suffice: the rap
  battle's spoken intro has p 0.65 and fuzzy 51 (it names the rappers). On newton this adds the announcer line
  (8 words), which voices then separates as its own voice (V1, centroid cosine <= 0.06 to every rapper).
  An ASR segment counts as covered when >= 30 % of it overlaps an aligned line (± 0.3/0.6 s).
- **M5-D12 ASR-guided repair**: a word whose LCS-matched whisper word (p >= 0.5) is > 1 s from the CTC start
  (after the median bias) is re-aligned in a tight window around the ASR time (kept when its score is >= max(0.05,
  0.5 x the old one)): CTC parks a line's first word in the previous word's tail when they share a sound.
- **M5-D13 overrides** `lyrics.lines {L001: {dt}}` / `lyrics.words {L001.03: {t, d, dt}}` are keyed by the ids
  this run assigns (start order) and applied after alignment, before the exports.
- **M5-D14 determinism**: faster-whisper runs with temperature 0 only (sampling fallbacks are random) and the
  library's default Silero VAD parameters (custom ones - 1 s silence / 300 ms pad - lost half of the rap
  battle's words: 217 vs 473); every model runs at `ctx.threads` on CPU. Measured: on newton the temperature-0
  run gives exactly the same 473 words as the default fallback schedule.
- **M5-D14b lead-vocal activity** for ASR gating and the hallucination filter = stem_activity's
  `stem.lead_vocals.active` OR the stem's own envelope activity (> p95 - 30 dB, hysteresis). stem_activity
  judges a stem against the mix, so a quiet vocal in a loud EDM mix (MEGAFAUNA) reads inactive everywhere.
- **M5-D14c ASR-guided repair is bounded** for synced sources by the line's source window (± slack, + offset):
  an ASR match outside it is another occurrence of a repeated word, not evidence.
- Exports: LRC (A2 word tags, `[ti]/[ar]/[al]/[length]` header), WebVTT (inline word timestamps, `<v hint>`),
  SRT (line level), ASS karaoke (`\k` centiseconds; gaps as empty `\k`; backing lines in a `Backing` style).

## voices additions

- `meta/voices.json`: `model`, `k_selection` (reason, eigengap k and Laplacian eigenvalues, silhouettes, 2-split
  centroid cosine), `centroid_cos`, `items`, `embedded_items`, `backing_spans`, `forced_lines`, `review_spans`;
  `voices[].lead_lines`.
- `events/voice_spans.json` items: `role` (`lead` | `backing`) and `source` (`embedding`, `hint`, `neighbour`,
  `override`, `intent`), documented in `fields`. A duet line has a lead span and a backing span.
- **M5-D15 n_source**: `intent` (intent.md voice count or character count) > `hints` (>= 2 distinct speaker labels
  in the lyrics source; the label decides) > `estimate` (1 voice when the 2-cluster split is not separated:
  centroid cosine >= 0.6 or silhouette < 0.08; else the best cosine silhouette at k >= the eigengap lower bound).
  Then, in estimate mode only, **minor clusters are folded** into their nearest voice: a single item whose
  centroid cosine to another voice is >= 0.25, or a cluster that never holds two consecutive lines, has < 15 %
  of the items and cosine >= 0.4 (one singer whose timbre changes on a few lines: Jeremy's 3 isolated lines,
  MEGAFAUNA's one effected line). A strongly foreign single item (an announcer) survives.
  `k_selection.merged_minor` records what was folded.
- **M5-D21 small samples**: with fewer than 24 embedded items (`small_n`) the estimate takes the eigengap lower
  bound itself instead of the best silhouette (on 16 items the silhouette rose monotonically to k = 4 on
  MEGAFAUNA, one cluster per odd line). The user's count (intent.md / overrides) still wins.
- **M5-D22** when the lyrics grade is D every estimated span is `review: true` (warning in the result): the
  embedding windows sit on unreliable word spans. Forced spans (override / intent) stay unflagged.
- **M5-D16 conf / review**: conf = 0.5 + 1.5 x (best - second-best centroid cosine), clipped; inherited (short
  item, < 1 s) spans get half their neighbour's conf; `review` = conf < 0.5 or inherited.
- **M5-D17 intent.md is read tolerantly**: `C1 ... voice V1` / `V2 = C3` (voice -> character), `voices: 4`
  (count), `L007: V2` / `L012 = C1+C2` (per line, what the viewer writes), character ids (`- C1 ...`) or the items
  of a "Characters" section (count). When the intent names exactly as many characters as voices but no mapping,
  `proposed_character_id` = C_k for V_k in order of first appearance (a proposal, noted in provenance).
- Voice ids are `V1..` by first appearance. Per-line overrides `voices.lines` win over intent.md lines.

## lipsync

- `vocal.mouth_open` (always) and `vocal.mouth_open.<V>` (>= 2 voices), D16. The gate is the sustain-extended
  word span (SPIKE) with ±80 ms pad and 5-frame soft edges; **a line's last-word hold stops at the next line's
  start** (another voice's line must not open this voice's mouth). Wordless vocal regions (envelope activity, no
  word within ±1 s, median level within 10 dB of the sung level, >= 0.5 s) are passed ungated to the nearest
  sung voice within 8 s (`fallbacks: lipsync:ungated_wordless`).
- Visemes: Rhubarb 1.14 per voice block (consecutive spans of one voice and role, gaps <= 2 s, <= 40 s), lead
  blocks on lead_vocals, backing blocks on backing_vocals, `-d` dialog from the block's lines in the stage scratch
  dir, deleted right after each run; `--threads 1` per process, blocks in parallel (deterministic). Each voice's
  timeline is filled with `X` outside its cues, so `visemes.allAt(t)` returns exactly one item per voice;
  `line_id` is null on fill segments.
- Phonemes (Could, delivered): g2p-en ARPAbet (stress digits removed) spread over each aligned word, vowels
  weighted x2, one item per voice singing the word.

## Review-fix round (fixer-m5)

- **M5-D30** (R-WORDS A/D) `align_groups`: a group window never reaches past the neighbouring group's first expected
  start (+0.15 s); the per-line window constraint is clipped to the neighbouring non-backing lines' placements; adjacent
  non-backing lines whose words interleave are re-aligned jointly (monotone by construction). New `alignment.notes`
  fields (additive): `crossings`, `crossings_fixed`, `crossings_left`, `lines_off_gt2s`; a warning (no lyric text) when
  any remain. ASR repair is judged on its own score (>= max(0.05, min(0.5 x old, 0.10))).
- **M5-D31** (R-WORDS A2, revised r2) emissions use the SPIKE recipe (30 s windows, 2 s context; the gate is calibrated on it); the 3 s before each window seam are replaced by frames of a seam-centred window with 8 s of context on both sides. A 6 s floor everywhere (round 1) moved newton G2/G4 out of grade B.
- **M5-D32** (R-WORDS B) inline `Name:` prefixes are speaker labels only in a labelled file: the same label recurs or a
  header names a speaker (enhanced-LRC `v1:`/`M:` prefixes always count). A one-off `Word:` stays sung text.
- **M5-D33** (R-WORDS C) hallucination filter covers the Whisper credit/outro phrases; `asr_only` lines also need
  `no_speech_prob < 0.6`.
- **M5-D34** (R-WORDS E) LRCLIB: candidates with lyrics rank ahead of instrumental-only ones; an instrumental flag is
  ignored (fallback `lyrics:instrumental_flag_ignored`, warning) when the ASR heard >= 8 words with p >= 0.5.
- **M5-D35** (R2-1, supersedes the label part of M5-D32) LRC ID/metadata tags (`[ar:]`, `[ti:]`, `[al:]`, `[by:]`, `[length:]`,
  `[offset:]`, `[re:]`, `[ve:]`, `[#:]`) are never speaker headers. A file is "labelled" when a `[Section: Name]` header names
  a speaker, or a name recurs (>= 2) among inline labels / bare `[Name]` headers. Bare headers containing an instrumental word
  (`[Guitar Solo]`, `[Sax Break]`) are never speakers.
- **M5-D36** (R2-2) `_asr_repair` clips its window to the previous line's last / next line's first placed word and skips a
  word whose ASR time lies beyond that edge; a warning is added when the repair leaves more interleaving line pairs than the
  alignment reported.
- **M5-D37** (R2-3) hallucination filter: credit strings (thanks for watching, transcribed by, URLs, `copyright ... <year>`)
  drop a segment unconditionally; ordinary-lyric-looking outro phrases (`see you next`, `please like/share`, bare
  `bye`/`goodbye`/`thank you`) only with a second signal (no_speech > 0.4, avg_logprob < -1, mean word p < 0.6, < 50 % vocal
  activity, or within 1 s of the audio start/end).
- **M5-D38** (R2-5) voices estimate mode: k = 1 when the best silhouette over the candidate k is below 0.2 (no cluster
  structure); the user's count (intent / overrides) stays the authority.

## W3 module fix round 1 (fixer-m5-r3)

- **M5-D47** (R3-1, R3-3; supersedes the labelled-file rule of M5-D35) speaker markers and labelled files:
  - a header is a section when ANY of its words is a section word (`[Final Chorus]`, `[Rap Verse]`, `[Pre Chorus]`,
    `[Post Chorus]`, `[Verse1]`); `pre chorus` / `post chorus` are joined;
  - `[Name:]` names the speaker before the colon; `[Name: Verse 1]` too (name first, section second);
  - a short capitalised name followed by `:` ALONE on its line (`Bill Nye:`, `Neil deGrasse Tyson:`) is a speaker
    marker, never a lyric line; the first word must not be a filler (`And`, `Listen`, `Baby` ...) and the last word
    must be capitalised (`Tell me why:` stays a lyric);
  - a file is labelled at once by an explicit marker (`[Verse 1: Newton]`, `Verse 1: Newton`, `[Newton:]`, `Newton:`);
    an inline `Name: ...` label counts only when it recurs with DIFFERENT text (a chorus line written out twice
    that starts with `Time:` is a repeated lyric); bare `[Name]` headers need >= 2 distinct names, one recurring.
- **M5-D48** (R3-4) unbracketed section headers in plain text (user / embedded): a whole line that is a section
  word with an optional qualifier (final, last, rap, ...), number, `:`, `xN` / `Nx`, or in parentheses
  (`Verse 1:`, `CHORUS`, `Chorus x2`, `(Chorus)`, `Verse 2: Newton`) is a header, not a sung line. An empty
  `(Chorus)` / `Chorus` re-inserts the last chorus block like `(Repeat chorus)`. `Chorus of angels ...` stays a lyric.
- **M5-D49** (S07) lipsync: when lyrics is instrumental (no lines, no words), the ungated wordless fallback is kept
  only for >= `instrumental_fallback_min_s` (new param, 8 s) of wordless vocals in total (a vocalise); a vocal chop or
  sample (Versatile: 0.55 s) leaves the mouth closed. A note records the suppression.
- **M5-D50** (S03) ASR gap retry: with a text source and a VAD pass, active lead-vocal spans >= `asr_gap_min_s`
  (new param, 6 s) that no ASR segment covers get a VAD-free faster-whisper pass (1 s context each side, same
  model instance, temperature 0); the hallucination filter (activity mask included) guards it. Additive
  `lyrics.json asr.gap_retry = {regions, seconds, segments, kept, words}`. New params `asr_gap_retry` (true).
- **M5-D51** (S03) G1 (lyrics_match_score) is judged where both sides have evidence: ASR words within the span the
  aligned text covers (lines ±1 s) against text words within the span the kept ASR segments cover (±1 s). ASR words
  in an outro without lines and text words in a VAD gap are no evidence of a wrong text. The G1 minimum of 8 ASR
  words applies to the scoped count. Additive `asr.g1_scope = {asr_words, asr_words_total, text_words,
  text_words_total, raw_f1}`; `asr.precision` / `asr.recall` are the scoped values. G7 and the per-word ASR check
  keep the full LCS.
- **M5-D47b** (R3-2, revises M5-D37) the generic-outro second signal no longer uses `no_speech_prob` alone: it needs
  `avg_logprob < -1`, or `no_speech_prob > 0.6` together with `avg_logprob < -0.7`, or mean word p < 0.6, < 50 %
  vocal activity, or a place within 1 s of the audio start/end. faster-whisper's no_speech_prob is per 30 s window
  and singing raises it (0.42-0.78 on confident sung segments of jeremy and newton).
- **M5-D52** (S03 part 2) lead-vocal activity after the last lyric line is reported (additive
  `alignment.vocals_after_last_line_s`) and, at >= `tail_vocals_warn_s` (new param, 20 s), flagged with a warning to
  review the outro (no lyric text). Lines are never invented for it: W0 measured Jeremy's 217-300 s outro as
  wordless singing (bench-words §2: a no-VAD pass returned 22 low-confidence words; the M5-D50 gap retry keeps 3).
  The mouth follows it through the lipsync ungated fallback.
- **M5-D53** (S03) G1 counts near-miss spellings as agreement: an ASR word of >= 4 letters that is not in the text
  within ±3 s but has a rapidfuzz ratio >= 80 with a text word there is compared as that word
  (`asr.canonicalise`). Measured: jeremy 0.697 -> 0.784, newton 0.851 -> 0.870; wrong-text controls (jeremy ASR vs
  newton text, newton ASR vs jeremy text) stay 0.064 / 0.042. Only G1 uses the canonical words: G7 and the
  per-word ASR check keep the exact LCS (with canonical pairs jeremy's G7 fell 0.62 -> 0.48: snapped words pair with
  repeats of a line elsewhere). `asr.g1_scope.near_miss_words` counts them; `raw_f1` keeps the exact, unscoped F1.
- **M5-D54** (R4-1, revises M5-D47; r4-m1) a `Name:` line on its own is only a speaker-marker CANDIDATE. The file
  accepts the set of candidates (`text._scan_labels`) when there are >= 2 distinct names and either one of them recurs
  with DIFFERENT text after it, or every one is a strict name (capitalised words and name particles, no pronoun or
  common verb) in a file that is not written in Title Case. Otherwise the lines stay sung lyrics: a quote-introducing
  line (`I said to John:`), a Title Case line (`Tell Me Why:`) or a chorus line written out twice that ends in `:`.
  This applies to every parser (LRCLIB synced LRC included). Bracketed `[Name:]` and section headers that name a
  speaker stay explicit. Header long tail: `*Chorus*` / `**Bridge**` (markdown emphasis), `Chorus (repeat)`,
  `1st Verse:` / `2nd Verse`, `[Verse 1 - Name]` / `Verse 1 - Name` (dash like colon), `Name (Verse 1):`, 5-word
  marker names; a lone `(x2)` line repeats the line before it (repeated-section expansion only adds more);
  `[Intro: Spoken]` names no speaker (a section or instrumental word after the colon is not a name).
- **M5-D55** (r4-m2) voices: a joint speaker hint (`Ann & Bob`, `Ann and Bob`, `Ann, Bob`, `Ann + Bob`, `Ann / Bob`,
  `feat.`) is split into its singers (`voices.core.hint_parts`), and `Both` / `All` / `Everyone` name no singer.
  With `n_source = hints`, k counts the distinct single names; a joint line is assigned to the nearest centroid
  among its own singers (source `embedding`, not `hint`), an unnamed joint line to the nearest centroid. meta
  `voices[].hint` counts single-name lines only.
- **M5-D56** (r3-m1) WITHDRAWN in the same round. Capping a line's held last word at the next lead line's start
  removed all 47 hold overlaps on newton, but it changes the voices item windows (52 -> 49 items, because chunking
  follows the line duration), and the estimated k on newton flipped from 4 to 3 (silhouette k3 0.344 vs k4 0.338).
  The W3 rule is that no change may regress a real song, so the hold stays as it was. The overlap is cosmetic for
  lipsync (it applies its own hold). A safe fix needs voices to take its item windows from word STARTS (or the
  uncapped spans), which is a coupled change for a later round.
