# M6a viewer: decisions and change requests

Owner: builder-m6a. Additive only; nothing in the frozen contract was edited.

## Decisions
- **V1 One self-contained page.** `viewer.html` = CSS + scripts + an inline copy of `src/mvh/assets/mvh.js` (loaded through a Blob URL, because ES-module imports fail on `file://`; under `mvh view` it first tries `lib/mvh.js` from the folder) + a zlib/base64 data bundle. `lib/mvh.js` loads that bundle through its `fetch` option, so the viewer uses the same helpers as video agents (no re-implemented helpers). The stage key includes a digest of the viewer sources (`params.assets`).
- **V2 Inlined preview data (size capped).** All `events/*`, `lipsync/*`, `meta/*`, lyrics, meaning, a reduced `curves/index.json` with only the drawn channels (`bundle.DEFAULT_CHANNELS`), a 1 kHz min/max waveform base, the spectrogram and `audio/preview.opus` (<= `inline_audio_max_mb`). Cap `inline_cap_mb` (28): the spectrogram, then the preview, are dropped first (summary + `viewer:*_not_inlined` fallback tags). Audio is always also referenced by relative URL (`audio/mix.flac`, `audio/preview.opus`, `stems/*.flac`); the inline preview is only a fallback.
- **V3 Lyrics inside viewer.html.** The user explicitly wants to read lyrics in the viewer, so lyric text is inlined (compressed). Param `viewer.inline_lyrics=false` (CLI `--param viewer.inline_lyrics=false`) removes it; served mode still shows lyrics from `lyrics/lyrics.json`. The integrator should set it when `--no-lyrics-to-agents` is implemented.
- **V4 Edit mode** only under `mvh view` (127.0.0.1, port 0 default, idle timeout 900 s, page pings every 15 s). Per-run token header `X-MVH-Token` + Host and Origin checks on every POST; the folder is served read-only (no dot or `_` path segments, Range for audio).
- **V5 Overrides writing.** `POST /api/overrides {overrides, etag}`: unknown sections/fields rejected (typos must not be silently ignored), schema `mvh/envelope/overrides` validated, atomic write (`mvh.io.atomic`), `If-Match`-style etag (409 on external change). Response lists affected stages = stages declaring a changed key (`StageSpec.override_keys`) + all transitive dependants, in topological order.
- **V6 Edit semantics.** Boundary edits are consolidated against the ORIGINAL boundary (moving twice keeps one `move` entry; moving back deletes it; remove of a moved boundary becomes a remove of the original). Line nudges are `dt` relative to the original time: `dt = wanted - (shown - applied_dt)` where `applied_dt` comes from the events provenance `overrides_applied` (`lyrics.lines`). Words are written with absolute `t`/`d`. Labels are anchored at the section midpoint. Pending rhythm edits are previewed in the lanes (offset, BPM, downbeat phase); the stage recomputes.
- **V7 Singers and meaning go to `meaning/intent.md` in a managed block** (`<!-- mvh-viewer:begin v1 --> ... <!-- mvh-viewer:end -->`, grammar in `stages/viewer/intent_block.py`). Text outside the block is preserved byte for byte; values cannot contain the markers. Line-to-voice is `overrides.json voices.lines`; voice-to-character is `- V1 = C1 Name` in the block; per-section meaning is `### S02 verse#1 9.000-17.000 s` with `feel/meaning/movement/camera/palette/do not` bullets, anchored by time.
- **V8 Re-run button** (`POST /api/rerun`, disable with `mvh view --no-rerun`) spawns `python -m mvh.cli analyze <folder>` in the same interpreter and shows the last 60 progress lines.
- **V9 Listening checks.** Click track generated in the browser from the (preview) beat grid and optionally drum hits (kick/snare/hat/tom/cymbal/perc), scheduled 150 ms ahead on the audio clock with a latency offset slider; stem solo/mute plays stem files in sync with the muted mix (drift corrected every 250 ms, ~30 ms typical).

## Change requests (for the W3 integrator)
1. **M5 voices / M6b meaning must read the managed block of `meaning/intent.md`** (voice-to-character lines and per-section meaning bullets, grammar above) as user-authored input, and `voices.lines` from overrides. Without it the viewer's saved singer/meaning edits have no effect on re-run.
2. `mvh analyze` could accept `--param viewer.inline_lyrics=false` automatically with `--no-lyrics-to-agents`.
3. CONTRACT.md D-list: add V1-V9 above (nothing frozen changes).
